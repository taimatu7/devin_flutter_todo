## 📝 Documentation Standards

All documentation in this project follows these standards:

- **Markdown Format**: All docs are in Markdown (.md)
- **Clear Headers**: Use hierarchical headers (#, ##, ###)
- **Code Examples**: Include code snippets where relevant
- **Links**: Use relative links to other docs
- **Table of Contents**: Include TOC for long documents
- **Up to Date**: Documentation is kept in sync with code
